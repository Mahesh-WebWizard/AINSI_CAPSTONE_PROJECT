🚗 Average Fuel Consumption Prediction using ANN (GUI App)

This project is a Python-based GUI application that predicts the average fuel consumption class of vehicles using Artificial Neural Networks (ANN). It allows users to load a dataset, train a model, make predictions, visualize results, and even generate synthetic data for testing.

📌 Features
📂 Upload and preview datasets (CSV format)

🧪 Generate train/test data with preprocessing and one-hot encoding

🤖 Train a deep learning model (ANN) using Keras

📈 Predict fuel consumption categories on new data

📊 Plot Actual vs Predicted results

🔄 Generate synthetic vehicle fuel data

🧠 Technologies Used
Python 3

Tkinter – for GUI

Pandas – for data handling

Matplotlib – for plotting

Scikit-learn – for preprocessing & train-test splitting

Keras (TensorFlow backend) – for ANN model
